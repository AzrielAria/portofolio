01.

Tentang Saya

Saya adalah Azriel Aria Wirata Nugraha, seorang pengembang web dan praktisi automasi asal Surabaya yang saat ini menempuh studi di Program Studi Sistem dan Teknologi Informasi, Universitas 17 Agustus 1945 (UNTAG) Surabaya.

Ketertarikan utama saya berada pada titik temu antara desain antarmuka yang bersih dan efisiensi sistem. Bagi saya, sebuah website atau skrip program tidak cukup hanya terlihat rapi—melainkan harus mampu menjawab kebingungan pengguna, mempercepat alur kerja klien, dan berjalan ringan di berbagai perangkat.

Melalui layanan freelance di Fastwork, Projects.co.id, serta kolaborasi langsung, saya fokus mengerjakan pengembangan landing page modern, perancangan UI/UX web, hingga skrip automasi dan ekstraksi data berbasis Python.
